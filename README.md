# 🩹 Wound Healing Tracker

A web-based application for recording and monitoring wound healing progress over time.

## 📌 About

The Wound Healing Tracker allows users to record basic wound information and maintain progress entries over time.

Users can record wound location, wound type, injury date, wound dimensions, healing stage, pain level, drainage, notes, and wound photographs.

The application also provides basic statistics and a visual representation of wound-size changes over time.

## ✨ Features

- Record initial wound information
- Add multiple healing progress entries
- Track wound length and width
- Record pain level
- Record drainage level
- Select healing stage
- Upload wound photographs
- Store data using browser local storage
- View healing progress timeline
- Display basic healing statistics
- Visualize wound size changes over time
- Export stored data

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
- HTML Canvas API

## 📱 Responsive Design

The interface is designed to work across desktop and mobile screen sizes.

## 🚧 Project Status

Currently under development.

Future improvements may include enhanced data visualization, improved image handling, and additional tracking features.

## ⚠️ Disclaimer

This project is an educational prototype for tracking and organizing wound-related information. It is not intended to provide medical diagnosis or replace professional medical advice.
